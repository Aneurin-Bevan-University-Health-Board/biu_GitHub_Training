## 📋 Overview

This comprehensive training series transforms GitHub from a developer tool into a powerful platform for healthcare analytics collaboration. The materials are designed for **interactive training sessions** with live demonstrations, hands-on exercises, and real-world healthcare analytics scenarios.

### 🎯 Training Philosophy

**Interactive Learning:** These materials are meant to be used alongside live instruction, not as standalone reading materials. Each session combines:

- 📊 **Live Demonstrations** - Instructor-led walkthroughs of GitHub features
- 🤝 **Hands-On Practice** - Immediate application with healthcare analytics scenarios  
- 💬 **Group Discussions** - Clinical and technical team collaboration
- 🏥 **Real-World Context** - Authentic healthcare analytics use cases
- ✅ **Skills Validation** - Practical competency assessments

### 🏥 Healthcare Analytics Context

Every exercise, example, and scenario is grounded in real healthcare analytics work:

- **Patient safety** and clinical quality improvement initiatives
- **Cross-site collaboration** between multiple healthcare facilities
- **Regulatory compliance** with GDPR, clinical audit, and healthcare information governance requirements
- **Clinical validation** processes and stakeholder engagement
- **Data governance** and information security considerations

### Session 1: Why GitHub for Data Teams
**Duration:** 30 minutes | **Format:** Interactive workshop with live demos

**Learning Focus:** Strategic foundation and core concepts
- GitHub vision and strategic benefits for healthcare analytics teams
- Healthcare analytics collaboration challenges and solutions
- Version control concepts with clinical data scenarios
- Basic GitHub terminology and core concepts

**Interactive Elements:**
- Live demo of GitHub transforming analytical workflows
- Group discussion on current collaboration pain points
- Hands-on account setup and basic repository exploration
- Team exercise creating first healthcare analytics repository

**Prerequisites:** None - suitable for complete beginners, but complete [Setup and Access](00_Setup_and_Access.md) first (account, organisation access and a personal access token)

### Session 2: Introduction to GIT
**Duration:** 45 minutes | **Format:** Conceptual workshop with demonstrations

**Learning Focus:** Understanding GIT as a version control system
- What GIT is and how it differs from GitHub
- GIT's core architecture and object model (blobs, trees, commits, tags)
- The three-tree architecture: working directory, staging area, and repository
- How GIT tracks changes and ensures data integrity
- The distributed model and its benefits for healthcare teams

**Interactive Elements:**
- Visual demonstrations of GIT's internal workings
- Interactive exploration of GIT object model
- Discussion of distributed version control benefits
- Understanding data integrity and security in GIT

**Prerequisites:** Session 1 completion

---

### Session 8: GitHub Codespaces and Copilot Hands-On
**Duration:** 45 minutes | **Format:** Demonstration followed by a hands-on build exercise

**Learning Focus:** Cloud development environments and AI-assisted coding
- GitHub Codespaces: what they are, launching, lifecycle and cost awareness
- Dev containers for a consistent environment across the team
- Information governance: what belongs in a Codespace, and what stays in the Secure Data Environment
- GitHub Copilot suggestions, chat and slash commands, and reviewing Copilot's output
- How GitHub and Codespaces fit alongside the SDE on Google Cloud Platform

**Interactive Elements:**
- Open a Codespace and explore the dev container
- Choose a track: **A. Analysis** (Python script that checks data, calculates DNA rates and charts them) or **B. UI** (Streamlit app with filters and charts)
- Build it with Copilot in small steps, then review its output with a checklist
- Commit, push and open a pull request for peer review

**Materials:** [`exercises/codespaces-copilot/`](exercises/codespaces-copilot/README.md) (synthetic dataset, instructions and instructor reference solutions)

**Prerequisites:** Sessions 1-7, a GitHub account with Copilot access, and permission to create a Codespace

## 📊 Training Structure and Delivery

### 🎪 Interactive Training Format

**Each session follows a proven interactive learning structure:**

```text
Session Structure (Example - Session 4):
├─ Introduction (5 minutes)
│  ├─ Learning objectives and context
│  ├─ Connection to previous sessions
│  └─ Healthcare analytics scenario introduction
├─ Live Demonstration (15 minutes)
│  ├─ Instructor-led feature walkthrough
│  ├─ Real healthcare analytics repository examples
│  └─ Interactive Q&A and discussion
├─ Hands-On Practice (8 minutes)
│  ├─ Individual exercises with guidance
│  ├─ Pair programming and collaboration
│  └─ Instructor support and troubleshooting
└─ Wrap-Up and Next Steps (2 minutes)
   ├─ Key learning recap
   └─ Preparation for next session
```

### 👥 Recommended Group Sizes

**Optimal Learning Environment:**
- **12-16 participants** for interactive workshops
- **4-person teams** for group exercises and simulations
- **Mixed roles** (analysts, clinical leads, developers, project managers)
- **Cross-site representation** when possible (multiple healthcare facilities)

### 🔧 Technical Requirements

**For Interactive Training Sessions:**

```text
Participant Requirements:
□ Laptop/workstation with admin rights for software installation
□ Reliable internet connection for GitHub access
□ Organisational network access for relevant systems
□ GitHub account creation capability
□ Basic computer literacy and file management skills

Instructor Requirements:
□ Projection/screen sharing capability for live demonstrations
□ GitHub organisation admin access for your organisation
□ Sample repositories and synthetic datasets prepared
□ Codespaces enabled and Copilot seats assigned (for Session 8)
□ Backup plans for technical difficulties
□ Experience with healthcare analytics workflows
```

### 📅 Delivery Options

**Flexible Training Formats:**

1. **Single Day Intensive Format** (Recommended)
   - All 9 sessions in one day, 09:00 - 15:00 including a 45-minute lunch break
   - Full team immersion and momentum building
   - Immediate application and practice

2. **Weekly Sessions Format**
   - One session per week over 9 weeks
   - Allows practice time between sessions
   - Better for busy clinical schedules
   - Requires more retention effort between sessions

3. **Two Half-Day Format**
   - Sessions 1-4 in first half-day (morning)
   - Sessions 5-9 in second half-day (afternoon or separate day)
   - Good for cross-site attendance
   - Manageable energy and focus requirements

## 🎯 Learning Outcomes and Assessment

### 📋 Competency Framework

**By completion, participants will demonstrate:**

#### Foundation Level (Sessions 1-4)
- ✅ Understanding of GitHub's value for healthcare analytics
- ✅ Understanding of GIT fundamentals and architecture
- ✅ Ability to navigate GitHub interface confidently
- ✅ Basic branching and merging operations
- ✅ Participation in code review processes

#### Intermediate Level (Sessions 5-6)  
- ✅ Proficient use of GitHub Desktop and advanced tools
- ✅ Integration of GitHub with development environments
- ✅ Management of large files and complex repositories
- ✅ Collaborative development with version control

#### Advanced Level (Sessions 7-9)
- ✅ Leadership of GitHub-based project management
- ✅ Implementation of automation and workflow optimization
- ✅ Training and mentoring of other team members
- ✅ Strategic planning for organizational GitHub adoption

#### Cloud Development Level (Session 8)
- ✅ Use of GitHub Codespaces and dev containers
- ✅ Responsible use of GitHub Copilot, with human review of its output
- ✅ Understanding of what belongs in GitHub and Codespaces versus the Secure Data Environment
