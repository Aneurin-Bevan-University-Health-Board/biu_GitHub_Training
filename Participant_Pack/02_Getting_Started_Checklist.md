# Getting Started Checklist

Tick each box. Full instructions are in [Setup and Access](../Training/00_Setup_and_Access.md).

## A. Before the day (about 30 minutes)

```text
□ I have a GitHub account using my NHS Wales email
□ I am a member of the ABUHB organisation and single sign-on works
□ Two-factor authentication is switched on
□ I can open the training repository and see the participants folder
□ I have found my own folder: participants/<firstname-lastname>
□ I have opened a Codespace on main and the terminal works
□ I have stopped that Codespace again
□ Optional: I am in the ndr-hb-abuhb-academy access group and can see the project in Google Cloud (for the SQL extension)
□ I have made a GitHub personal access token, only if my trainer asked for one
□ I have read the crib sheet
```

Stuck on any box? Email the GitHub admin team: `ABB.BIU.GitHub.Admin@nhswales365.onmicrosoft.com`, with your GitHub username.

□ Notebook or the notes template ready
