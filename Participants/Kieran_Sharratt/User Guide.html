1. Getting Started

  1. Ensure the dashboard has been started. If you manage the app yourself, follow the setup instructions in section 11.
  2. In Codespaces, open VS Code's Ports panel and select Open in Browser for port 8501. Sign in to GitHub if requested.
  3. For a locally running dashboard, open http://localhost:8501 on the same computer.
  4. Wait for the data to load, then select a tab. On narrow screens, expand the sidebar to reach historical match filters.

The historical tabs use locally exported Cricsheet deliveries. Upcoming Tests and Live Scores retrieve BBC Sport data over the internet. Ground-map background tiles also require internet access.

You can read this guide offline. Use your browser's Print command and choose Save as PDF for a printable copy. Enable background graphics to retain the shaded flowcharts. Trebuchet MS is used when installed on the viewing device; otherwise, the browser uses a sans-serif fallback.

3. Historical Match Filters

  1. Under Match Selection, choose Men, Women or Both. The initial selection is Men.
  2. Set both ends of Match start dates. A match is selected by its start date, not by whether any part of the match overlaps the range.
  3. Optionally choose Opposition, Ground and England result. Leaving a selector empty includes all options for that field.
  4. Read the summary metrics: Tests, England wins, Grounds and Recorded deliveries. They describe the filtered historical selection, not the live feed.

Several selections in one field are alternatives; selections across different fields are combined. For example, two opposition teams plus one ground returns matches against either team at that ground.

If there are no results, widen the date range or remove individual opposition, ground or result selections. If only one date is entered, complete the end date.

4. Match Centre

  1. Apply the historical filters, then open Match Centre.
  2. Use Match to select a Test. The list shows the date, opposition, venue and men's or women's team, with the newest matches first.
  3. Review the venue, date and result, then the innings table showing team, runs, wickets and overs.
  4. Inspect the cumulative-runs chart. Each line represents an innings; the horizontal axis counts recorded deliveries, including illegal deliveries, rather than legal balls or overs.
  5. Expand All selected matches to see the wider filtered match list.
  6. Select Download matches to export all matches in the historical selection, not just the Test selected in the Match dropdown.

Where available, hover over a chart to inspect values. Historical totals are reconstructed from recorded deliveries and may differ from an official scorecard where adjustments are not captured in those deliveries.

5. Player Statistics

  1. Set the sidebar filters for the matches you want to analyse.
  2. Open Player Statistics and choose England, Opposition or All under Players.
  3. Choose Batting or Bowling under Discipline.
  4. Optionally enter all or part of a name in Player name. The search ignores upper/lower case. Clear the search to restore all matching players.
  5. Review the chart and full table. The chart shows up to 12 leading players by runs or wickets within the current selection and search.
  6. Select Download player statistics to export the current player table, including its scope, discipline and name filter.

6. Ground Map

  1. Apply the historical filters and open Ground Map.
  2. Zoom or pan to the area of interest. Hover over a marker to see the ground, country and number of selected Tests.
  3. Use the table below the map to compare ground counts. Larger markers represent more Tests, not larger venues or higher scores.
  4. Select Download ground counts to export venue counts and catalogue information.

Coordinates are approximate. Known venue-name aliases are combined into one ground on the displayed map and table. The download retains venue-level rows, so aliases may appear separately there.

An unmapped-ground warning means a venue has no coordinate match in the local catalogue. It may still appear in the downloaded venue counts but will not have a map marker. An unavailable background map can indicate blocked tile requests or no internet connection.

7. Upcoming Tests

  1. Open Upcoming Tests.
  2. Choose Men, Women or Both. This tab always limits fixtures to England.
  3. Review scheduled Tests listed by BBC from today through the next 365 days. Fixtures are ordered by start time; completed or already-in-progress matches are excluded.
  4. Read the teams, series description, scheduled start, venue and scheduled end. Start times are displayed in UK time, using GMT or BST as appropriate for the fixture date.
  5. Select Refresh fixtures to request updated data or BBC scorecard to open the corresponding BBC page.

The Updated timestamp shows when the dashboard fetched the response, not when BBC last changed a fixture. Future dates and venues can change. An empty list means no matching England Tests were returned by BBC in this period, not proof that none are scheduled.

8. Live Scores

  1. Open Live Scores. The displayed date is today's date in the Europe/London time zone.
  2. Choose Men, Women or Both. Initially, Both is selected and Tests involving all nations are eligible.
  3. Turn on England matches only to restrict the list to England. If no England Test is listed, turn it off to see other nations' Tests.
  4. Review each match's status, match day, BBC summary and team innings. Matches that started on an earlier day can appear because Tests span multiple days.
  5. The live section refreshes automatically every 60 seconds while the app session remains active. Use Refresh scores for a manual update.
  6. Select BBC scorecard for further information on BBC Sport.

Reading the score

250/8 dec (80.2 ov) means 250 runs for eight wickets, declared, after 80 overs and two legal balls. A completed all-out innings can appear as 100 (30.0 ov), without a wickets suffix. An ampersand separates two innings for the same team. Yet to bat means BBC supplied no innings for that team.

Today's list may contain scheduled, in-progress or finished matches. A listed Test is not necessarily being played at this instant: there may be an interval, rain delay or a gap between days. Automatic refresh does not guarantee ball-by-ball updates, and background browser tabs may refresh less frequently.

BBC coverage: the dashboard uses BBC Sport's public website data endpoint, not a guaranteed supported public API. Coverage can be incomplete, delayed or unavailable. A failed request produces a warning; historical CSV statistics are not substituted for live scores.

Key statistical definitions
FieldMeaning in this dashboard
Matches / appearancesMatches with recorded batting or bowling participation, not full team-sheet selections. Batting participation includes a recorded non-striker.
Batting averageRuns divided by recorded dismissals. Blank when there are no dismissals.
Batting strike rateRuns per 100 balls faced. Balls faced exclude wides but include no-balls.
Bowling averageBowler-conceded runs divided by credited wickets. Blank when there are no credited wickets.
EconomyBowler-conceded runs per six legal balls.
Bowling strike rateLegal balls per credited wicket.
OversCompleted overs followed by remaining legal balls. For example, 10.3 means 10 overs and three balls, not 10.3 decimal overs.
Credited wicketsBowled, caught, caught and bowled, lbw, stumped and hit wicket. Run-outs are not credited to the bowler.
Bowler-conceded runsDelivery totals less byes, leg-byes and penalty extras.

Important limitations

  • The historical dataset covers the available Cricsheet deliveries, not every England Test.
  • Adjustments outside recorded deliveries, declarations, follow-on status and victory margins are not represented in the historical innings data.
  • Historical innings wickets exclude retired hurt and retired not out. Batting dismissals include run-outs.
  • Player names are source labels rather than unique registry IDs. Combined views can pool matching name labels across datasets.
  • Changing historical filters changes aggregate statistics. Compare players only after confirming the selected matches and scope.

11. Setup and Data Maintenance

This section is for the person running or maintaining the dashboard. Ordinary users do not need to run these commands.

Install and start

From the repository root, run:

python -m pip install -r Participants/Kieran_Sharratt/requirements.txt
python -m streamlit run Participants/Kieran_Sharratt/cricket_dashboard.py --server.port 8501

Keep the process running while users access the dashboard. In Codespaces, use the forwarded port URL from the Ports panel; the URL can change between Codespaces.

Refresh historical data

  1. Open england_test_matches.ipynb in the Kieran_Sharratt folder.
  2. Set the notebook's OUTPUT_DIR to this folder's cricsheet_exports directory and run the export workflow.
  3. Confirm that england_male_tests_deliveries.csv and england_female_tests_deliveries.csv are available there.
  4. Reload the dashboard. Its data cache uses export file modification times to detect changes.

The app resolves data paths relative to its own location. Export files are generated data and are not tracked by Git. Ground coordinates and aliases are maintained in cricket_venues.csv.

Run the checks

python -m unittest discover -s Participants/Kieran_Sharratt -p test_cricket_dashboard.py -v

The tests cover historical calculations, export/map coverage, BBC Test filtering and innings formatting. They do not guarantee future BBC endpoint availability or complete fixture coverage.
